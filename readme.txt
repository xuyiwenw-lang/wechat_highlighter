Wechat_highlighter 插件

这是一个简单的浏览器插件，主要有两个功能：

1.  解锁限制：让你可以在一些禁止复制内容的网页上（如微博、扑克财经等）自由选中与复制文字。
2.  句子高亮：当鼠标移动到文章段落上时，会自动以句子为单位进行高亮显示，方便阅读。

如何安装

你可以通过以下几个简单的步骤，在你的浏览器（如 Chrome等）上手动安装这个插件：

1.  准备文件：
    *   创建一个新的文件夹，名字可以随便取，比如 `Wechat_highlighter`。
    *   把 `manifest.json`、`content.js` 和 `styles.css` 这三个文件都放进你刚创建的这个文件夹里。

2.  打开浏览器扩展页面：
    *   打开你的浏览器。
    *   在地址栏输入 `chrome://extensions` (如果用的是 Chrome) 并按回车。

3.  开启“开发者模式”：
    *   在扩展页面的右上角，找到并打开“开发者模式”的开关。

4.  加载插件：
    *   开启开发者模式后，页面左上方会出现几个新的按钮。
    *   点击“加载已解压的扩展程序”按钮。
    *   在弹出的窗口中，选择你第一步创建的那个 `wechat_highlighter` 文件夹，然后确认。

完成以上步骤后，插件就安装好了，它会自动在指定的网站上生效，无需额外操作。
